# Introdução ao JavaScript

## Sobre a atividade
Esta atividade tem como objetivo introduzir os conceitos fundamentais da linguagem JavaScript, explorando sua sintaxe e suas principais funcionalidades.

## Conteúdos estudados
- Declaração de variáveis (`let` e `const`);
- Tipos de dados e operadores;
- Estruturas condicionais (`if` e `else`);
- Laços de repetição (`for`);
- Funções, parâmetros e retorno (`return`);
- Manipulação de elementos HTML com JavaScript;
- Eventos e interação com a página.

## Mini projeto
Ao final da atividade, foi desenvolvido um pequeno sistema para calcular a média de duas notas, validar os valores informados e apresentar o resultado ao usuário.

## Tecnologias utilizadas
- HTML
- JavaScript
- Visual Studio Code
